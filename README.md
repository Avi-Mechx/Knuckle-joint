# 🔩 Knuckle Joint – AutoCAD 3D Model

This repository presents a 3D CAD model of a **Knuckle Joint** designed using AutoCAD.  
It is a mechanical joint used to connect two rods under tensile load while allowing slight angular movement.

---

## 📌 About the Project

The model includes all major components of a knuckle joint:
- Eye end  
- Fork end  
- Knuckle pin  
- Collar  

The design demonstrates proper assembly and working of the joint used in real mechanical systems.

---

## 🛠️ Tools Used
- AutoCAD (3D Modeling)

---

## ✨ Design & Assembly Features

- Accurate 3D modeling of each component  
- Complete assembly visualization  
- Proper alignment of pin and fork  
- Realistic proportions based on mechanical design  

---

## ⚙️ Applications

- Tie rod joints  
- Suspension systems  
- Structural link mechanisms  
- Mechanical power transmission
