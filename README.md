Knuckle Joint 3D Model (AutoCAD)

This repository contains the 3D model of a Knuckle Joint created using AutoCAD.

---

About Knuckle Joint

A knuckle joint is a mechanical joint used to connect two rods subjected to tensile load.
It allows slight angular movement between the connected rods without failure.

---

Applications

- Tie rod joint
- Suspension system
- Structural link connections
- Mechanical power transmission systems
